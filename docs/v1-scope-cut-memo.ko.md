# Runimal v1 스코프 컷 메모

## Keep

- 워치 러닝 의식성과 러닝 종료 후 iPhone 반영
- 첫 3회 러닝 약속
- 희귀 변이의 특별함
- 최종 진화의 목적지 감각

## Cut For Launch

- 시즌/레이드/지역 팩을 메인 가치처럼 전면 배치하는 문서/카피
- 신규 기본 종 확장 논의
- 장기 운영 전제의 복잡한 역할 메타 설명
- “언젠가 가능한 것”을 현재 제품 가치처럼 보이게 하는 홈 UI 문맥

### 컷 이유

- 첫 3회 러닝 감정선보다 뒤의 메타가 먼저 보이면 v1 집중력이 무너진다.
- 공개 출시 전에는 `많아 보이는 게임`보다 `즉시 살아 있는 게임`이 더 중요하다.
