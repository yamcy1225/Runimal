# Runimal In-App String Proposal

## FTUE

- 첫 알 생성: `첫 러닝이 알이 됩니다`
- 부화 완료: `숨겨진 생명이 깨어났습니다`
- 첫 성장: `처음으로 자랐습니다`

## 희귀 / 완성

- 희귀 변이 획득: `밤의 흔적 고정`
- 최종 진화 해금: `완성된 호흡 도달`
- 공유 카드 제목: `내 러닝이 만든 생명`

## 적용 우선순위

- 우선 적용: egg creation, hatch, first stage-up, rare mutation, showcase share
- 시즌 1 보강: 종족별 세부 flavor, Sanctuary / weekly mission 세부 문구 확장
