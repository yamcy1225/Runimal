# Runimal v1 Lock

## 한 줄 판타지

완주한 러닝이 그대로 생명이 된다.

## 첫 세션 약속

- 첫 완주 직후 `???` 알이 바로 생긴다.
- 워치에서 함께 달린 감각과, 폰에서 남는 운동 기록은 분리돼 읽힌다.
- 첫 보상은 숫자보다 “무언가 태어났다”는 감정으로 기억돼야 한다.

## 세 번의 러닝 약속

- 첫 러닝 = 첫 알
- 둘째 의미 있는 러닝 = 첫 부화
- 셋째 의미 있는 러닝/첫 먹이 주기 = 첫 단계 상승

## v1에서 반드시 지키는 것

- Apple Watch는 실시간 동행/의식의 장치다.
- iPhone은 보상 정리, 부화, 성장, 보관, 공유의 허브다.
- 운동 기록 화면은 “러닝 결과”이고, 실시간 동행 화면과 섞이지 않는다.
- 희귀 변이는 숫자보다 시각적으로 먼저 읽혀야 한다.
- 공유 카드는 게임 결과처럼 보여야지 운동 로그 캡처처럼 보이면 안 된다.

## v1 제외 항목

- 복잡한 시즌 스토리 분기
- 풀 raid/party 메타
- 과한 소셜 기능
- 심층 장비/육성 트리 확장
- 수십 종 런치 종족 확장

## Kill / Keep / Later

### Kill

- 런치 전에 핵심 3회 약속을 흐리는 시스템
- “운동 유틸”로 읽히는 건조한 보상 표현
- 실시간 동행과 운동 기록의 용도 혼합

### Keep

- starter egg -> hatch -> first stage-up의 또렷한 FTUE
- watch ritual / phone hub 구조
- 희귀 변이 / 공유 카드 / 보관함의 수집 동기

### Later

- 시즌별 대형 이벤트
- raid readiness 확장
- 고난도 후반 성장 메타
- Mac 전용 편의 확장
