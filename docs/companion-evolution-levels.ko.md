# 동행 종족별 진화 레벨 기준

동행의 진화는 공통 XP 숫자만으로 밀지 않고, 종족별 성장 리듬에 맞춘 레벨 마일스톤으로 계산한다.

기본 단계는 <code>알 → 유아기 → 유년기 → 청소년기 → 성년기</code>다.

## 설계 원칙

- 레벨은 전체 성장 속도의 공통 언어로 쓴다.
- 진화 시점은 종족 성향에 따라 다르게 잡는다.
- 초반 반응이 빠른 종은 첫 단계가 빠르고, 완성에 시간이 걸리는 종은 후반 단계가 늦다.
- 무거운 종, 특수종은 최종 단계 요구치를 뒤로 둔다.

## 종족별 기준

### 던스프리그

- 레벨: Lv.5 / Lv.11 / Lv.18 / Lv.24
- 누적 XP: 132 / 513 / 1392 / 2599
- 이유: 입문형이라 첫 반응은 빠르게 열고, 이후 갈래와 완성은 충분히 길게 끌어 장기 육성형 캡과 맞춘다.

### 신더래시

- 레벨: Lv.5 / Lv.12 / Lv.19 / Lv.25
- 누적 XP: 132 / 611 / 1558 / 2850
- 이유: 속도와 케이던스에 빨리 반응하지만, 성년기는 템포와 열기를 오래 붙잡아야 안정된다.

### 에이라리스

- 레벨: Lv.6 / Lv.13 / Lv.20 / Lv.27
- 누적 XP: 179 / 717 / 1736 / 3394
- 이유: 장거리 적응형이라 초중후반 간격을 가장 고르게 벌리는 표준 장기 성장선이다.

### 모스베일

- 레벨: Lv.6 / Lv.14 / Lv.21 / Lv.28
- 누적 XP: 179 / 832 / 1926 / 3687
- 이유: 첫 반응은 어렵지 않지만, 안정된 호흡과 회복 리듬이 오래 쌓여야 뒤 단계가 열린다.

### 크래그맨틀

- 레벨: Lv.6 / Lv.15 / Lv.22 / Lv.29
- 누적 XP: 179 / 957 / 2138 / 3995
- 이유: 무겁고 느리게 자라는 종이라 유년기 이후 모든 단계가 한 템포 늦고, 최종 완성도 가장 묵직하다.

### 셰이드빗

- 레벨: Lv.6 / Lv.16 / Lv.23 / Lv.30
- 누적 XP: 179 / 1092 / 2362 / 4319
- 이유: 황혼 계열 특수종이라 형태 안정화가 가장 늦고, 성년기 요구치도 가장 높다.

## 적용 방식

- 상세 화면 성장 과정에서 각 단계 카드에 다음 진화 레벨과 누적 XP를 함께 표시한다.
- 실제 진화 판정도 종족별 레벨 마일스톤에 대응하는 누적 XP 기준으로 계산한다.
- 첫 단계 보정도 종족별 첫 진화 컷에 맞춰 같이 계산한다.
- 성년기 도달 시점은 대체로 Lv.24~30에 오도록 맞춰, 최대 레벨 50과의 거리도 자연스럽게 유지한다.
