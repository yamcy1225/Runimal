# Runimal S급 전환 체크리스트

## 1. 목표

이 문서는 현재 Runimal을 `실기기 플레이 가능한 vertical slice`에서 `S급 모바일 게임 제작사 수준의 출시 준비 상태`로 끌어올리기 위한 우선순위 체크리스트다.

핵심 원칙:

- 첫 러닝 3회 안에 핵심 루프를 반드시 체험시킨다.
- 알, 부화, 성장, 진화, 변이를 시스템 설명이 아니라 감정적 보상으로 느끼게 만든다.
- Apple Watch는 단순 기록 기기가 아니라 `실시간 플레이 기기`여야 한다.
- iPhone은 선택, 보상, 수집, 성장, 시즌 메타를 정리하는 허브여야 한다.

## 2. 현재 상태 요약

현재 Runimal은 다음을 이미 구현했다.

- Apple Watch 실기 러닝 시작/종료
- 운동 기록 보상 생성
- 숨김형 `???` 알 시스템
- 함께 달릴 동행 / 지금 선택한 알 선택
- 부화 시네마틱
- 경험치 공급과 진화 연출
- 5단계 진화
- 희귀 변이 5종
- 주간/시즌/레이드/빌드 트리의 뼈대

즉, `코어 루프는 구현 완료` 상태다.

부족한 것은 다음이다.

- 첫 세션 온보딩 압축
- 희귀 변이 외형/연출 차별화
- 장기 리텐션용 콘텐츠 밀도
- 계측/코호트 기반 밸런스 튜닝
- 공유하고 싶어지는 결과물

## 3. 최우선 실행 순서

### 3.1 FTUE 압축

목표:

- 첫 러닝: `??? 알 생성`
- 둘째 러닝: `첫 부화`
- 셋째 러닝: `첫 단계 상승`

이 구간은 랜덤이나 실패 케이스에 맡기지 말고, 시스템적으로 거의 보장해야 한다.

실행 항목:

- 빈 슬롯에서의 첫 러닝으로 생성되는 알은 `starter egg`로 취급
- starter egg는 둘째 러닝 1회 인큐베이트로 부화 보장
- starter egg에서 태어난 첫 동행은 첫 먹이 주기에서 최소 `유아기` 도달 보장
- 홈 화면의 스타터 루프 패널을 `첫 알 → 첫 부화 → 첫 단계 상승` 기준으로 재작성

### 3.2 희귀 변이 쇼케이스 강화

목표:

- 희귀 변이를 숫자/텍스트가 아니라 `한눈에 다른 존재`로 느끼게 한다.

실행 항목:

- Tempo Surge / Zen Bloom / Summit Heart / Eclipse Mark / Loop Sigil 각각 전용 외형 레이어 강화
- 부화 직후 일반 개체와 희귀 개체의 등장 연출 차등화
- 변이별 전용 사운드/배너/색 신호 확실히 분리

### 3.3 최종 진화 가치 강화

목표:

- 완성이 단순 상위 단계가 아니라, `목표가 되는 최종 단계`가 되게 한다.

실행 항목:

- 완성 전용 타이틀
- 완성 전용 신호와 보상 컷
- 시즌 포커스와 연결되는 전용 명칭 강화

### 3.4 리텐션 계측

목표:

- 재미를 감으로 판단하지 않고 코호트로 확인한다.

필수 이벤트:

- `first_run_completed`
- `egg_created`
- `egg_hatched`
- `first_stage_up`
- `rare_variant_obtained`
- `weekly_reward_claimed`

지표:

- D1 / D7 / D30
- 첫 러닝 완료율
- 첫 알 생성률
- 첫 부화 도달률
- 첫 Stage Up 도달률

### 3.5 시즌/레이드 엔드게임화

목표:

- 장기 이용자가 `계속 뛰어야 하는 이유`를 만든다.

실행 항목:

- 시즌 전용 진화 분기 강화
- 레이드 보스 패턴과 결과 표현 강화
- 시즌 종료 보상과 다음 시즌 예고 연결

### 3.6 공유물 고도화

목표:

- 러닝 결과를 기록 카드가 아니라 자랑 카드로 만든다.

실행 항목:

- 첫 부화 카드
- 희귀 변이 획득 카드
- 완성 진화 카드
- Strava / 인스타 스토리용 짧은 세로형 렌더

## 4. 완료 기준

다음이 충족되면 `S급 전환 1차`로 본다.

- 첫 3회 러닝 내 핵심 루프 체험 보장
- 희귀 변이의 외형/연출 차이 체감 가능
- 완성이 명확한 장기 목표로 보임
- 핵심 계측 이벤트 수집 가능
- 시즌/레이드가 장기 루프를 형성
- 공유물이 실제로 올리고 싶은 수준으로 개선
