# Runimal 현재 캐릭터 디자인 고정 원칙

이 문서는 지금 사용자 확인을 거쳐 만족도가 높다고 판단된 캐릭터 디자인 상태를 보존하기 위한 잠금 문서다.

목적은 단순하다.

- 지금 좋아진 방향이 이후 수정에서 무너지지 않게 한다.
- 새 디자이너나 개발자가 들어와도 무엇을 건드리면 안 되는지 바로 알게 한다.
- 성장 단계, 종 구분, 색 정체성, UI 배치를 같은 원칙으로 계속 유지하게 한다.

## 최상위 원칙

- 귀여움은 `작고 약한 느낌`이 아니라 `안정적인 비율 + 익살스러운 표정 + 종별 차이`로 만든다.
- 종 구분은 `과한 장식`이 아니라 `실루엣`, `볼선`, `몸통 비율`, `상단 포인트` 차이로 만든다.
- 성장은 `크기만 커지는 것`이 아니라 `같은 개체가 자연스럽게 성숙하는 것`처럼 보여야 한다.
- 같은 종은 유아기부터 성년기까지 같은 색 정체성을 유지해야 한다.
- UI 배지나 프리뷰 라벨은 캐릭터를 절대 가리면 안 된다.

## 유아기 고정 원칙

- 유아기는 무조건 `아기스럽고 익살스러운` 인상이 먼저 읽혀야 한다.
- 머리가 몸보다 약간 크게 읽혀야 한다.
- 얼굴은 좌우 대칭이 맞아야 한다.
- 눈, 볼, 입 주변 흰 면적은 표정을 살리되 과하게 찌그러지면 안 된다.
- 희귀 변이, 시즌 장식, 성숙형 장갑/볏/돌기 같은 요소는 유아기에서 드러나면 안 된다.
- 종 차이는 남겨야 하지만, 유아기 전체 톤은 같은 세계관의 아기들처럼 묶여야 한다.

## 종 구분 원칙

### 에이라리스

- 가장 기본형에 가까운 둥근 유아기
- 바람형답게 가볍고 열린 인상
- 너무 무겁거나 각지면 안 된다

### 크래그맨틀

- 더 넓고 낮은 하체
- 무게중심이 아래에 있어야 한다
- 유아기라도 버티는 느낌이 아주 약하게는 보여야 한다

### 신더래시

- 상단 귀선/전면 반응선이 살아 있어야 한다
- 날카로움은 남기되 공격적으로 과해지면 안 된다
- 유아기에서는 장난기 쪽이 먼저 읽혀야 한다

### 모스베일

- 가장 포근하고 둥근 체형
- 볼선과 몸통 폭이 넓어도 무너져 보이면 안 된다
- 보호형의 부드러움이 먼저 읽혀야 한다

### 던스프리그

- 작고 응축된 새싹형
- 상단 발아 포인트는 유지하되 좌우 균형이 무너지면 안 된다
- 유아기에서 가장 작은 코어감이 보여야 한다

## 성장 단계 원칙

- `알 → 유아기 → 유년기 → 청소년기 → 성년기`는 하나의 개체가 자연스럽게 이어지는 흐름이어야 한다.
- 유아기와 유년기는 귀여움이 우선이다.
- 청소년기부터 체형 차이와 고유 포인트가 더 선명해진다.
- 성년기는 성숙해 보여야 하지만, 유아기와 완전히 다른 종처럼 보이면 안 된다.
- 각 단계는 이전 단계의 핵심 인상을 보존한 채 확장되어야 한다.

## 색 정체성 원칙

- 색은 `species` 기준으로 고정한다.
- 성장해도 종 고유색 hue는 유지한다.
- 희귀 변이와 시즌은 기본색 위에 얹히는 보조층이다.
- 서로 다른 종이 같은 톤으로 겹쳐 보이면 안 된다.
- 현재 기준 색은 `docs/world/species-color-identity.ko.md`를 따른다.

## UI 배치 원칙

- 캐릭터가 카드 안에서 가장 중요한 정보다.
- 배지, 프리뷰 문구, 상태 라벨은 캐릭터 위에 겹치지 않는다.
- 원형 배경, 글로우, 그림자는 좌우 중심이 맞아야 한다.
- 캐릭터가 원형 안에서 치우쳐 보이면 디자인 완성도가 크게 떨어진다.

## 금지 규칙

- 유아기에서 희귀 변이 실루엣을 미리 노출하지 말 것
- 종 구분을 위해 과한 장식물을 얹지 말 것
- 기본색을 원소나 이벤트 색으로 덮어쓰지 말 것
- 좌우 대칭이 필요한 얼굴/몸체를 비대칭으로 방치하지 말 것
- 배지나 텍스트가 캐릭터를 가리게 두지 말 것

## 수정 전 체크리스트

- 이 수정이 유아기의 아기스러움을 해치지 않는가
- 이 수정이 5종 종 구분을 더 선명하게 만드는가
- 이 수정이 기본색 정체성을 흐리지 않는가
- 이 수정이 같은 개체의 성장 연속성을 유지하는가
- 이 수정이 캐릭터를 UI 요소보다 덜 중요하게 만들지 않는가
