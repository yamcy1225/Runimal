# Runimal Species And Mutation Bible

## 1. 목적

이 문서는 현재 기본 종족 5종과 향후 변이 트리 설계를 위한 최소 바이블이다.

핵심 원칙은 아래와 같다.

- 각 종족은 러닝 데이터의 특정 성격을 대표한다.
- 변이 트리는 종마다 완전히 따로 놀지 않고 공통 골격을 가진다.
- 희귀 변이는 단순 스킨이 아니라 러닝 습관의 각인이다.

## 2. 현재 종족 목록

- Windrunner
- Stoneback
- Sparkfang
- Mosshop
- Seedle
- Shadebit: 독립 기본 종이 아닌 황혼 계열 special form

## 3. 종족별 기본 정체성

### Windrunner

- 상징: 바람, 순항, 거리, 길잡이
- 기본 속성 해석: `light`
- 잘 반응하는 러닝: 장거리, 안정 페이스, 낮은 흔들림
- 시각 키워드: 날개, 길게 흐르는 선, 가벼운 잔광
- 감정 키워드: 자유, 안내, 신뢰
- 역할 판타지: 멀리 갈수록 더 강해지는 동행체

### Stoneback

- 상징: 암석, 인내, 언덕, 수호
- 기본 속성 해석: `earth`
- 잘 반응하는 러닝: 오르막, 누적 고도, 저항성 주행
- 시각 키워드: 단단한 등갑, 육중한 다리, 암석 패턴
- 감정 키워드: 버팀, 의지, 안정감
- 역할 판타지: 넘어지지 않는 방패형 동행체

### Sparkfang

- 상징: 화염, 질주, 폭발, 사냥
- 기본 속성 해석: `flame`
- 잘 반응하는 러닝: 빠른 템포, 고케이던스, 짧은 강도 훈련
- 시각 키워드: 송곳니, 스파크, 꼬리 잔광
- 감정 키워드: 흥분, 추진력, 승부욕
- 역할 판타지: 순간 폭발력이 강한 추격형 동행체

### Mosshop

- 상징: 숲, 회복, 순환, 휴식
- 기본 속성 해석: `leaf`
- 잘 반응하는 러닝: 자연 구간, 편안한 심박, 완만한 거리 누적
- 시각 키워드: 이끼, 둥근 체형, 부드러운 표면
- 감정 키워드: 평온, 회복, 포근함
- 역할 판타지: 함께 숨을 고르게 해주는 회복형 동행체

### Seedle

- 상징: 씨앗, 발아, 시작, 적응
- 기본 속성 해석: `leaf` 또는 입문형 중립축
- 잘 반응하는 러닝: 첫 러닝, 균형형 기록, 회복 러닝
- 시각 키워드: 씨앗, 새싹, 작은 팔다리
- 감정 키워드: 가능성, 성장, 애착
- 역할 판타지: 가장 많은 파생 가능성을 품은 시작형 동행체

## 4. 공통 변이 트리 골격

모든 종족은 아래 3축을 공통으로 갖는다.

### 축 A: 체형 계통

- Swift: 빠르고 가벼운 형태
- Guard: 무겁고 단단한 형태
- Wild: 규칙 밖으로 벗어난 이형

### 축 B: 생태 계통

- Urban: 도심 적응형
- Wildland: 자연 적응형
- Twilight: 야간/이상권 적응형

### 축 C: 리듬 계통

- Rhythm: 케이던스 우세형
- Pulse: 심박/감정 공명형
- Route: 경로 문양형

## 5. 종족별 우선 변이 방향

### Windrunner

- 대표 파생 예시:
  - Gale Swift
  - Trail Guide
  - Loop Feather

### Stoneback

- 추천 우선 축: Guard, Wildland, Pulse
- 대표 파생 예시:
  - Ridge Guard
  - Summit Core
  - Fault Shell

### Sparkfang

- 추천 우선 축: Swift, Urban, Rhythm
- 대표 파생 예시:
  - Tempo Fang
  - Neon Rush
  - Ember Sprint

### Mosshop

- 추천 우선 축: Guard, Wildland, Pulse
- 대표 파생 예시:
  - Bloom Rest
  - Rain Moss
  - Heart Canopy

### Seedle

- 추천 우선 축: 전 축 개방
- 대표 파생 예시:
  - Sprout Swift
  - Root Guard
  - Twilight Seed

### Twilight Form: Shadebit

- 분류: Sparkfang/Seedle 기반 황혼 계열 form
- 추천 우선 축: Twilight, Route, Echo
- 대표 파생 예시:
  - Eclipse Twilight
  - Maze Route
  - Echo Bud

## 6. 현재 희귀 변이의 해석

### Tempo Surge

- 조건 감성: 고케이던스, 빠른 페이스
- 추천 연결 종: Sparkfang, Windrunner
- 시각 효과: 선명한 잔광, 날카로운 테일, 가속 흔적

### Zen Bloom

- 조건 감성: 안정 페이스, 차분한 리듬
- 추천 연결 종: Mosshop, Seedle
- 시각 효과: 부드러운 광륜, 차분한 채도, 꽃잎 문양

### Summit Heart

- 조건 감성: 상승 고도, 언덕 지속력
- 추천 연결 종: Stoneback
- 시각 효과: 광물 심장, 능선 문양, 단단한 체형

### Eclipse Mark

- 조건 감성: 야간, 그림자, 저조도
- 추천 연결 종: Sparkfang, Seedle, Shadebit form
- 시각 효과: 달빛 표식, 검은 윤광, 눈동자 발광

### Loop Sigil

- 조건 감성: 루프 경로, 반복 패턴
- 추천 연결 종: Windrunner, Sparkfang, Shadebit form
- 시각 효과: 문양 띠, 원형 궤적, 반복 궤도

## 8. 구현 우선순위

1. 현재 기본 종 5종의 `SpeciesBibleEntry` 작성
2. 종당 3개씩 대표 변이 계통 우선 정의
3. 희귀 변이 5개를 종족별 연결표로 확정
4. 도감 문구와 부화 문구에 반영

## 9. 최종 원칙

종족은 수집 대상이 아니라 러닝 습관의 성격을 가진 생명체여야 한다.
변이는 난수 결과가 아니라 플레이어의 반복된 몸의 리듬이 남긴 흔적처럼 느껴져야 한다.
