# Runimal 게임 컨셉 및 보상 시스템

## 1. 제품 정의

Runimal은 iPhone과 Apple Watch를 기반으로 하는 러닝 동행 육성 게임이다.

이 게임은 단순히 러닝 기록을 저장하는 앱이 아니라, 현실의 달리기 데이터를 `디지털 틈새 세계(Digital Gap)`와 연결해 알, 동행, 성장, 진화로 번역하는 구조를 가진다.

핵심 한 줄은 다음과 같다.

- 현실에서 뛴 기록이 틈새 세계의 암호화된 데이터 블록이 되고, 그것이 부화 과정을 거쳐 동행으로 실체화된다.

## 2. 핵심 판타지

플레이어가 느껴야 하는 감정은 다음과 같다.

- 내가 뛴 기록이 실제 생명체처럼 반응한다.
- 어떤 러닝을 하느냐에 따라 다른 결과가 나온다.
- 지금 보상을 현재 주력 동행에 줄지, 미래를 위한 새 알로 바꿀지 선택할 수 있다.
- Apple Watch에서의 실시간 러닝이 단순 운동이 아니라 생성과 성장의 의식처럼 느껴진다.

## 3. 세계관

Runimal의 세계관은 `디지털 틈새 세계`를 중심으로 한다.

- 현실 세계 이면에는 보이지 않는 디지털 층위가 존재한다.
- 러너의 운동 에너지는 현실과 틈새 세계를 동기화하는 유일한 신호다.
- 러닝 종료 후 얻는 운동 기록은 단순 점수가 아니라 틈새 세계에서 끌어온 데이터 조각이다.
- 알은 생물학적 알이 아니라 `암호화된 데이터 블록`이다.
- 부화는 틈새 세계 데이터가 앱 위에서 실체화되는 과정이다.

## 4. 핵심 플레이 루프

### 4.1 러닝 루프

1. Apple Watch에서 러닝을 시작한다.
2. 거리, 케이던스, 심박, 페이스, 고도 등 라이브 데이터가 기록된다.
3. 러닝 중에는 실시간 목표, 희귀 신호, 달성 이벤트가 워치에서 바로 피드백된다.
4. 러닝 종료 시 운동 기록 보상이 확정된다.
5. 보상은 iPhone으로 동기화된다.
6. 플레이어는 보상을 현재 메인 대상에 맞게 사용한다.

### 4.2 동행 루프

1. 플레이어는 펫과 알을 보유한다.
2. 동시에 하나의 함께 달릴 동행 또는 하나의 부화 준비 알만 정해 둔다.
3. 지금 선택한 대상이 동행이면 보상을 성장 재료로 사용한다.
4. 지금 선택한 대상이 알이면 새로운 러닝으로 부화 준비를 진행한다.
5. 알이 준비되면 부화 시네마틱을 통해 새 동행이 생성된다.

### 4.3 장기 루프

1. 러닝 수행
2. 업적 달성
3. 특정 러닝에서만 새 알 획득
4. 컬렉션 확장
5. 빌드/역할 강화
6. 주간 보상, 시즌 보상, 레이드 보상 획득
7. 더 희귀한 변이체와 상위 콘텐츠로 진입

## 4.4 첫 3회 러닝 약속

Runimal v1은 아래 감정 흐름을 첫 3회 안에 반드시 보여 줘야 한다.

1. 첫 러닝: 첫 `???` 알 생성
2. 둘째 러닝: 첫 부화
3. 셋째 러닝 이후 첫 의미 있는 먹이 주기: 첫 단계 상승

이 구간은 운이 좋으면 보이는 보너스가 아니라, 제품 정체성을 증명하는 기본 약속이다.

## 5. 대표 선택 시스템

플레이어는 항상 하나의 메인 대상만 유지한다.

### 5.1 지금 선택한 동행

메인이 펫일 때:

- 운동 기록을 지금 선택한 동행에게 먹일 수 있다.
- 성장, 진화, 빌드 보정이 지금 선택한 동행 기준으로 누적된다.
- 휴식일 보상도 지금 선택한 동행 기준으로 계산된다.

### 5.2 지금 선택한 알

메인이 알일 때:

- 새 러닝이 지금 선택한 알의 인큐베이트 재료가 된다.
- 알의 실제 정체는 숨겨진 채 진행도와 껍질만 보인다.
- 플레이어는 결과를 확정적으로 아는 대신, 행동 조건으로 특정 계열 확률을 밀어올릴 수 있다.

## 6. 알 시스템

## 6.1 알의 표현 방식

알은 처음부터 정체를 공개하지 않는다.

- 이름은 `???`로 시작한다.
- 플레이어는 껍질 타입만 본다.
- 껍질별 스캔 헤드라인과 로그가 노출된다.
- 실제로 어떤 펫이 나오는지는 부화 완료 전까지 숨겨진다.

알은 “정답 카드”가 아니라 “확률이 기울어진 미지의 데이터 블록”이어야 한다.

### 6.2 알 획득 조건

모든 러닝이 알이 되는 구조는 아니다.

새 알을 만들 수 있는 러닝은 다음 둘 중 하나를 만족해야 한다.

1. 이번 러닝으로 새 업적을 해금했을 때
2. 펫 슬롯과 알 슬롯이 모두 비어 있는 상태에서 첫 성공 러닝을 마쳤을 때

이 규칙은 알을 희귀하고 의미 있는 보상으로 유지한다.

### 6.3 껍질 타입

현재 껍질 타입:

- Ember
- Gale
- Moss
- Dusk
- Stone

각 껍질은 러닝 패턴의 결과물이다.

- Ember: 빠른 페이스, 높은 케이던스, 공격적 리듬
- Gale: 장거리, 꾸준한 이동, 속도 계열
- Moss: 균형형, 안정형, 성장형
- Dusk: 야간, 변칙 리듬, 미스터리
- Stone: 고도, 언덕, 견고함

### 6.4 확률 구조

부화 결과는 랜덤이지만 완전 랜덤은 아니다.

최종 결과는 다음 요소의 영향을 받는다.

- 껍질 타입
- 알을 만든 러닝
- 이후 인큐베이트에 사용한 러닝들
- 현재 받은 주간 효과

즉 플레이어는 결과를 미리 볼 수 없지만, 어떤 러닝을 하느냐로 특정 종족과 계열 확률을 밀어올릴 수 있다.

### 6.5 부화 시네마틱

알의 부화는 일반적인 “깨짐”이 아니라 4단계 부화 시퀀스로 표현된다.

1. 부화 준비
2. 부화 진행 중
3. 신호 정리 중
4. 부화 완료

현재 연출 요소:

- 스캔 로그
- 글리치 그리드
- 간섭 배경 레이어
- 조각 분해 이펙트
- 완료 직전 플래시
- 생성된 펫 등장

## 7. 펫 시스템

### 7.1 종족

현재 주요 종족:

- Windrunner
- Stoneback
- Sparkfang
- Mosshop
- Shadebit
- Seedle

### 7.2 희귀 변이

희귀 변이는 상위 수집 대상이다.

현재 희귀 변이 예시:

- Tempo Surge
- Zen Bloom
- Summit Heart
- Eclipse Mark
- Loop Sigil

희귀 변이는 러닝 패턴과 특정 조건이 맞을 때 등장 확률이 열린다.

### 7.3 성장과 진화

펫은 다음 요소를 통해 성장한다.

- Run Core 경험치
- 반복적인 러닝 기록
- 주간 효과
- 빌드 노드
- 시즌 보정

진화는 단순 레벨업이 아니라 누적된 플레이 패턴의 결과로 설계한다.

## 8. Run Core와 보상 시스템

러닝 종료 후 플레이어는 Run Core를 받는다.

Run Core는 다음 정보의 묶음이다.

- 코어 라벨
- 경험치
- flavor text
- 완료한 퀘스트 수
- 생성된 펫 계열 해석

### 8.1 Run Core 사용 선택지

Run Core는 다음 세 방향으로 사용된다.

1. 새 알 만들기
2. 메인 펫 성장
3. 메인 알 인큐베이트

하나의 러닝은 최종적으로 한 곳에만 귀속된다.

### 8.2 러닝 중 런타임 알림

Apple Watch 러닝 중 다음 이벤트가 발생하면 즉시 피드백이 온다.

- 라이브 목표 달성
- 희귀 신호 감지
- 러닝 종료 후 보상 확보

피드백 수단:

- 상단 알림 배너
- 햅틱 큐

## 9. Apple Watch 역할

Apple Watch는 실시간 플레이 기기다.

주요 역할:

- 러닝 시작/종료
- 라이브 수치 표시
- 실시간 목표 추적
- 희귀 신호 감지
- 달성/보상 이벤트 배너
- 메인 알 공명 표현

Watch는 기록 장치가 아니라, 러닝 중 플레이 판단을 유도하는 인터페이스여야 한다.

## 10. iPhone 역할

iPhone은 관리와 해석의 허브다.

주요 역할:

- 대표 선택
- 알/펫 컬렉션 관리
- Run Core 사용 결정
- 부화 시네마틱 재생
- 주간/시즌/빌드/레이드 흐름 정리
- 휴식일 보상 확인

단, v1의 iPhone은 시즌/레이드 심화 허브가 아니라 `운동 기록을 누구에게 줄지 결정하고, 알을 깨우고, 첫 성장을 확인하는 홈 베이스`여야 한다.

## 11. 휴식일 보상: Sanctuary Mode

러닝이 없는 날에도 앱에 접속할 이유를 만들기 위해 Sanctuary Mode가 존재한다.

- 메인 펫이 틈새 세계를 탐색한다.
- 총 누적 거리와 빌드 역할에 따라 Essence나 아이템을 가져온다.
- Oracle 계열은 이 보상 탐색 확률에 유리하다.

즉, 휴식일은 손해가 아니라 작은 탐색 기회다.

## 12. 주간 / 시즌 / 레이드

현재 메타 구조는 다음과 같다.

- 주간 미션과 주간 보상
- 시즌 보드
- 시즌 전용 해금
- 레이드 준비도와 보상
- raidContribution 기반 장기 확장 대비

현재 제품은 이미 수집형 러닝 게임의 코어 루프를 갖췄고, 앞으로는 시즌/레이드/콘텐츠 볼륨을 확장하는 방향으로 발전한다.

## 13. 설계 원칙

Runimal은 다음 원칙을 유지한다.

- 결과는 숨기되, 행동 힌트는 충분히 준다.
- 러닝은 게임 재료이지, 단순 로그가 아니다.
- 랜덤은 존재하지만 플레이어 선택이 확률을 기울여야 한다.
- iPhone은 관리와 해석, Watch는 실시간 자극과 판정에 집중한다.
- UI는 설명보다 그래픽과 즉시 피드백으로 읽히게 만든다.
