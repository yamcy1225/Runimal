# Runimal UI Before / After Note

## Before

- Home는 데이터는 많지만 왜 `러닝이 생명이 되는지`를 한 번에 읽기 어려웠다.
- First Stage-Up은 캡처 하네스가 깨져 placeholder가 노출됐다.
- Rare Mutation은 희귀 상태 자체보다 목록 성격이 먼저 읽혔다.
- Showcase Share는 포스터보다 리스트처럼 보여 공유 욕구가 약했다.

## After

- Home 상단에 v1 약속과 Watch 실시간 / iPhone 사후 보상 구분을 추가했다.
- First Stage-Up은 고정 fixture로 재현되고, `FIRST STAGE UP` 배너와 대비 보강으로 즉시 읽힌다.
- Rare Mutation은 활성 변이를 먼저 보여 주는 spotlight 블록으로 희귀성을 바로 전달한다.
- Showcase Share는 poster frame, stamp, title hierarchy를 강화해 `올리고 싶은 카드` 느낌을 높였다.
