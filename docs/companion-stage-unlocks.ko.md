# 동행 성장 단계별 해금 기준

동행 성장 단계는 <code>알 → 유아기 → 유년기 → 청소년기 → 성년기</code>로 고정한다.

## 원칙

- 단계는 이름만 바꾸는 장식이 아니라 플레이어가 체감하는 기능 해금 단위로 쓴다.
- 현재 단계에서는 지금 가능한 상호작용을, 다음 단계에서는 곧 열릴 변화를 짧게 보여준다.
- 러닝 후 얻은 운동 기록은 누구에게든 줄 수 있고, 단계 해금은 그 기록을 어떻게 먹였는지에 따라 쌓인다.

## 단계별 기준

### 알

- 상태: 아직 성장으로 바뀌기 전 대기 단계
- 해금: 부화 준비, 첫 기록 대기
- 전환 기준: 첫 운동 기록 투입

### 유아기

- 상태: 기본 반응이 생기기 시작하는 단계
- 해금: 기본 반응, 종족 성향 확인, 기본 교감 보너스
- 실제 보너스: 하루 첫 교감, 잘 맞는 종류, 목표 달성, 월드 개방 보너스
- 기대 행동: 자주 먹이는 기록의 톤이 이 아이의 초반 성격을 만든다

### 유년기

- 상태: 익숙한 길과 시간대의 취향이 자리 잡는 단계
- 해금: 길/시즌 힌트, 기록 선택 폭 확대, 안정 보너스
- 실제 보너스: 시즌 호흡, 익숙한 길 보너스 추가 해금
- 기대 행동: 플레이어가 어느 기록을 누구에게 줄지 의식하게 만든다

### 청소년기

- 상태: 변이와 이야기 갈래가 드러나는 단계
- 해금: 변이 힌트, 에피소드 신호, 반응 수 증가
- 실제 보너스: 변이 공명, 이야기 신호 해금, 상호작용 XP 상한 소폭 증가
- 기대 행동: 데리고 달릴지, 기록을 먹일지의 선택이 서사와 성장에 함께 영향을 준다

### 성년기

- 상태: 방향이 굳고 장기 운영 가치가 생기는 단계
- 해금: 장기 성장 보너스, 시즌 시너지 강화, 완성 기록 보관
- 실제 보너스: 상호작용 XP 상한 추가 증가, 시즌 호흡 추가 보너스 <code>+6 XP</code>
- 기대 행동: 단순 레벨업보다 시즌/변이/기록 조합 운영이 중심이 된다

## 성년기 이후 레벨 해금

성년기 안에서도 <code>Lv.31 / 35 / 40 / 45 / 50</code>에 별도 후반 해금을 둔다.

### Lv.31 기록 해석

- 의미: 풍부한 운동 기록에서 추가 정보를 읽는다
- 실제 보너스: 기록 밀도 보너스가 충분한 기록에 <code>+6 XP</code>
- 실제 기능: 성장 반영 결과에서 운동 기록 태그를 기본 2개 대신 4개까지 보관한다

### Lv.35 잠재 응축

- 의미: 함께 달리며 쌓은 잠재를 더 진하게 전환한다
- 실제 보너스: 동행 잠재를 실제로 소비한 먹이에 <code>+6 XP</code>
- 실제 기능: 저장 가능한 잠재 한도가 <code>60 → 80</code>, 한 번에 사용할 수 있는 잠재 상한이 <code>+4</code> 늘어난다

### Lv.40 시즌 숙련

- 의미: 시즌과 맞는 동행이 후반부에 더 안정적으로 성장한다
- 실제 보너스: 시즌 호흡이 맞는 먹이에 <code>+8 XP</code>
- 실제 기능: 시즌과 맞는 러닝을 먹였을 때 그 시즌 기록을 별도 표식으로 함께 보관한다

### Lv.45 이야기 정착

- 의미: 구역/에피소드 신호를 자기 기록으로 굳힌다
- 실제 보너스: 이야기/구역/시즌 개방 신호가 있는 먹이에 <code>+10 XP</code>
- 실제 기능: 구역, 시즌, 에피소드 해금 신호를 결과 태그에 직접 남긴다

### Lv.50 완성 기록

- 의미: 더 오르기보다 완성된 개체로서 기록을 남기는 단계
- 실제 변화: 성장 보너스보다는 완성 표식과 기록 보관 의미가 중심이다
- 실제 기능: 운동 기록 태그를 5개까지 보관하고, 잠재 저장 한도도 <code>90</code>까지 확장한다
