# RunimalRewardV2

Draft reward/growth boundary for Runimal v2.

Goal: preserve the Runimal rule that completed workouts are unassigned run resources until the player manually spends them.

This layer should wrap existing `RunimalCore` engines first, then expose smaller v2 use cases:

- make run resource
- preview live companion potential
- feed companion
- forge egg
- incubate egg

Not yet declared in `Package.swift`.
